# FDC 금융 판단 모델 연구 소스

최신 사용자 범위의 네 요소는 [금융 코어 V3 구현 기록](FINANCIAL_CORE_V3.md)을 따른다. V3 계약·생성기·입력 변환·전체 출력 조건 변경 손실·정확한 합성 제약 보정을 Cherry CPU에서 검증했다. 이 문서 아래의 V2 수치는 이전 실험 기록이다.

[TRON 실관측 릴리스](REAL_TRON_DATA_20260924.md)는 공식 USDD 일별 기록 366개와 JustLend 확정 이벤트 800개를 원문과 대조한다. 별도 자기지도 실험으로 FDC의 시계열 인코더만 학습했으며, 단순 지속값 기준선을 넘지 못했다. 배분 계획 헤드는 실데이터로 학습되지 않았다.

[소비자용 데이터·지속 학습 계약](CONSUMER_GRADE_DATA_LEARNING_20260924.md)은 정기 수집, 수정 감지, 새 일자의 전진 평가와 학습 후보 게이트를 정의한다. 2026-09-24부터 Cherry에 일별 연구용 작업이 설치되어 있다.

[배분 판단 오라클](ALLOCATION_ORACLE_20260924.md)은 모델 제안을 입력 조건과 독립적으로 대조하고 합성 제약 사례 7,935개를 채굴한다. 실제 금융 판단 정답이나 모델 승격 자료는 아직 아니다.

`fdc/model.py`는 Qwen API 래퍼가 아닌 학습 가능한 금융 결합 코어다. 시계열, 상품 관계, 근거, 확인된 사용자 제약을 공동 처리하고 배분·근거·질문·유보 점수를 낸다. `fdc/features.py`는 에피소드 V2를 고정 차원 텐서로 바꾸고, `fdc/train.py`는 합성 사례에 한정해 학습·평가 보고서를 만든다. `fdc/validate.py`는 JSONL 스키마, 예산 보존, 근거 참조, 분할 누출을 검사한다. 원천 API로 만든 사례 초안은 `excluded/unreviewed`라 이 학습기에 들어갈 수 없다.

2026-09-24 사용자 지시에 따라 Cherry CPU에서 1,000개 합성 시나리오 가족, 2,000개 에피소드를 검증·학습했다. 자체 가중치 체크포인트와 보고서가 `data/runs/`에 있다. 합성 홀드아웃 222건에서 문자 해시 FDC의 제약 손실 전/후 모드 일치율 94.1%/95.5%, 원시 배분 제약 위반률 22.2%/4.1%, 배분 평균 절대오차 0.059/0.091이었다. 고정 다국어 E5-small 인코더를 연결한 FDC는 각각 99.1%/3.1%/0.092, 단순 MLP 기준선은 87.4%/22.2%/0.144였다. **실제 금융 성능은 검증되지 않았다.** Mac에서는 테스트나 학습을 실행하지 않았다.

텍스트 입력은 결정론적 문자 해시 기준선과 [MIT 라이선스 다국어 E5-small](https://huggingface.co/intfloat/multilingual-e5-small)의 고정 인코더 실험을 구분한다. 고정 인코더는 Qwen 32B가 아니고 금융 판단 자체를 학습시키지 않았다. `train.py`의 결과는 생성 규칙이 같은 합성 홀드아웃에 한정되며 독립 평가, 현재 금융시장 성능, JEV 비교, 거래 가능성으로 해석하지 않는다.

원시 금액은 Decimal 문자열로 에피소드와 정본에 남기고, 모델에는 근사 특징만 넣는다. 모델의 배분 확률은 거래 지시가 아니다. 정확한 수수료·잔액·승인·경로 검사가 별도로 성립해야 하며, 현재 사용자 UI에는 FDC 출력을 연결하지 않았다.

Cherry에서 `python -m unittest discover -s tests -v`의 최신 29개 테스트가 통과했다. 원문 무결성·정규화 값 대조·과거 시점 절단, V3 단위·출금·공통 위험·조건 변경 가족·모델 출력 검사를 포함한다. 독립 검토 에피소드와 Qwen 32B 기준선 비교는 없다. 실제 API 관측은 시계열 자기지도 학습에만 썼고 배분 라벨의 권한과 사람 검토가 없어 계획 학습에는 넣지 않았다. 구조·목표는 [모델 연구 명세](../FINANCIAL_MODEL_ARCHITECTURE_20260923.md)를 따른다.
