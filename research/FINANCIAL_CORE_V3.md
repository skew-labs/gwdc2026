## 데이터셋 현황

`synthetic-v3-1000.jsonl`은 1,000개 가족, 2,000개 **합성** 사례다. 가족 단위 학습/개발/합성 홀드아웃은 1,596/198/206건이며, 한 조건 변경 쌍은 `changed` 792개, `unchanged` 208개다. 제안/질문/유보는 1,689/142/169건이다. [`validate_v3.py`](fdc/validate_v3.py)는 JSON Schema, 원시 Decimal 문자열, 자산 단위, 시점, 출금 조건, 예산 보존, 공통 위험 한도, 근거 ID, 합성 oracle 일치, 가족별 split 격리를 검사한다. 생성 규칙과 평가 규칙이 같으므로 이 수치들은 독립 금융 골드셋이 아니다.

공식 API의 실제 응답은 [`api_draft_v3.py`](fdc/api_draft_v3.py)로 V3 **입력 초안**을 만들었다. 사용 조건은 [`typed_api_example_need.json`](../cases/typed_api_example_need.json)의 작성 예시이며 실제 사용자 발화가 아니다. 출금 조건·원천 관측 시각을 API로 확인하지 못한 부분은 `null`로 남겼다. 초안은 `excluded / unreviewed / rights_unknown / abstain`으로 검증됐고 학습에 넣지 않았다. 원천 수집 시각은 시장 사건 시각의 대체물이 아니다.

## Cherry CPU 합성 실험

아래는 같은 생성 규칙의 206건 합성 홀드아웃과 첫 계획의 정확 보정 평가다. 수치가 낮을수록 좋은 열은 `보정 후 배분 오차`, `변경 쌍 변화량 오차`, `유지 쌍 흔들림`이다. 홀드아웃을 여러 연구 설정에 반복 사용했으므로 모델 선택에 독립적인 봉인 평가로 주장하지 않는다.

| 설정 | 모드 정확도 | 질문 필드 정확도 | 근거 F1 | 원시 첫 계획 위반 | 보정 후 배분 오차 | 변경 쌍 오차 | 유지 쌍 흔들림 |
|---|---:|---:|---:|---:|---:|---:|---:|
| FDC, 배분·모드 쌍 손실 0.1, 문자 특징 | 100% | 100% | 0.683 | 25.6% | 0.0611 | 0.0582 | 0.0074 |
| FDC, 전체 출력 쌍 손실 0.1, 문자 특징 | 100% | 100% | 0.700 | 33.1% | 0.0748 | 0.0694 | 0.0095 |
| FDC, 쌍 손실 없음, 문자 특징 | 100% | 100% | 0.710 | 33.1% | 0.0766 | 0.0756 | 0.0174 |
| FDC, 배분·모드 쌍 손실 0.1, 고정 E5-small | 100% | 100% | 0.671 | 25.6% | 0.0683 | 0.0639 | 0.0013 |
| 평면 MLP, 배분·모드 쌍 손실 0.1, 문자 특징 | 95.6% | 5.3% | 0.583 | 37.8% | 0.0836 | 0.0514 | 0.0009 |

정확 보정 뒤 위 실험들의 알려진 합성 제약 위반은 0건이다. 이는 **보정 규칙의 결과**이며 신경망이 제약을 완벽히 학습했다는 뜻이 아니다. 변경 쌍의 보정 후 오차에서 MLP가 FDC보다 낮은 설정도 있어 자체 구조의 일관된 우위는 입증되지 않았다. FDC는 MLP보다 큰 모델이고 처리시간·비용 우위도 입증되지 않았다. 모델 체크포인트·학습 보고서·보정 보고서는 Cherry의 `data/runs/`에 보존했다.

실험 재현 시 `train_v3.py --pair-objective allocation_mode`는 위 표의 배분·모드 쌍 손실, `--pair-objective full`은 계획 수·근거·의존성·질문까지 포함한 전체 출력 쌍 손실이다. `--pair-loss-weight 0`은 같은 모델의 쌍 손실 제거 실험이다. 새 보고서·체크포인트에는 목적함수 버전을 기록한다.

현재 합성 oracle은 동일 자산의 세 후보, 단순 공급 금리 순위, 현금·출금·공통 위험 한도에 한정된다. 실제 수수료, 지갑, 검증된 상품 출금 약관, 여러 프로토콜 공통 위험의 독립 라벨, 사람 검토 골드셋은 없다. 이 자료만으로 실제 금융 판단 성능이나 JEV급 성능을 주장하지 않는다.

이 생성 규칙과 별도로 [배분 판단 오라클](ALLOCATION_ORACLE_20260924.md)을 구현했다. 이 오라클은 모델 제안의 예산·출금·공통 위험·근거 제약을 정답 필드 없이 다시 검사하고, 실원천 약관이 없으면 유보한다. 합성 판정 7,935건은 제약 보조 학습 자료일 뿐 실제 배분 정답은 아니다.

초기 V3 구현 당시 Cherry에서 관련 단위·계약 검사를 포함해 전체 테스트 19개가 통과했다. 입력 계약과 모델 손실은 구현됐지만 실자료 **배분 판단** 학습, 독립 평가, 추론 제품 연결은 별도 검증이 필요하다.

## 2026-09-24 TRON 실관측 추가

[실관측 데이터 릴리스](REAL_TRON_DATA_20260924.md)에서 USDD TRON 일별 366건과 JustLend jUSDT·jUSDD 확정 이벤트 800건을 원문 해시·단위·시각과 대조했다. FDC의 시계열 인코더만 366건의 자기지도 다음 날 예측으로 학습했으며, 홀드아웃에서 단순 지속값 기준보다 오차가 컸다. 실제 배분 정답은 0건이고 계획 출력 헤드는 실데이터로 학습되지 않았다. TRON API 입력 초안에는 네트워크·프로토콜 버전·underlying 주소/자릿수를 명시하고, 모르는 출금 조건 때문에 여전히 유보한다. 최신 전체 테스트는 Cherry에서 29개 통과했다.
